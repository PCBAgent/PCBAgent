# Parts

Read `designs/<slug>/design/circuit-spec.json`, `designs/<slug>/design/ic.json` when it exists, and `designs/<slug>/design/skidl_sim.py`. Write `designs/<slug>/parts/`. `/design` runs this after verification passes, or immediately after the simulation file when `skip_verify` is true.

The part source is the local JLCPCB cache at `.tools/jlcpcb/economic-parts.csv`. If that file is missing, download it once:

```bash
.venv/bin/python skills/parts/fetch_catalog.py
```

Then choose parts without using the network:

```bash
.venv/bin/python skills/parts/lookup.py designs/<slug>
```

`parts/parts.json` is the catalog result. Every manufacturer part number, value, tolerance, voltage, current, power, package, stock, price, and basic or preferred status in that file was copied from the cache. Do not invent them. The footprint matcher records whether the mapping is exact or heuristic. A heuristic suggestion is unverified and cannot pass the parts gate. When `design/ic.json` exists, the regulator in `parts.json` is that same part. A part with `matched` false or `changes_measured_value` true stops this stage. A value change means the simulation has to be revised. `on_board` false requires the reference to appear in `circuit-spec.json.external_components`; equal resistance alone never identifies an external load. A `D()` in the simulation is the catch diode of an asynchronous regulator. Lookup matches it to a Schottky rated for the supply and the load current. `external_diode` true on `ic.json` with no `D()` in the simulation stops this stage: add the diode and simulate again. The KiCad netlist places that diode anode to ground and cathode on the switch net.

Write `parts/skidl_kicad.py` from the matched on-board parts, using `from skidl import *` and `set_default_tool(KICAD)`. Use the `symbol` and `footprint` fields from `parts.json`. Connect `U1` by the pin `number` in `design/ic.json`, on the same nets as `skidl_sim.py`: `u1[1] += vin`, not `u1['VIN']` or `u1['~{EN}']`. Tie every ground pin number, including hidden ones, to ground. Verify enable polarity from the selected datasheet and connect that pin accordingly; do not infer polarity from the role map. An adjustable part keeps the feedback divider. An asynchronous part keeps the catch diode. The file calls `ERC()` and `generate_netlist(file_="board.net")`. Then run:

```bash
.venv/bin/python skills/parts/netlist.py designs/<slug>
```

A missing footprint aborts the netlist. Do not place parts or draw traces.

Use `pcb_stage` for `parts` and `netlist` commands. Selection consumes fresh `design/simulation-evidence.json`, generated by verification from the executed circuit. Resistors must meet measured power and voltage stress; capacitors must meet voltage stress. Missing applicable ratings or measurements (including inductor/diode current when unavailable) are unverified. Do not invent missing evidence. Catalog ratings do not prove thermal performance or IC model fidelity.

Write actual passive values and preserve simulated nets. The manufacturing validator rejects stale generation, malformed/empty netlists, missing parts, changed values/nets, invalid or unconnected symbol pins, and missing footprint pads. It writes `parts/netlist-report.json`, saves rejected output as `rejected.net`, and withholds `board.net` on failure. Intentional unused IC pins need explicit engineering resolution; the initial validator conservatively requires all non-NC pins to be connected.

Use previous failures to guide the next repair. Report unresolved checks and continue working; only the user cancels execution. Never change the spec or part values solely to make a check pass.
